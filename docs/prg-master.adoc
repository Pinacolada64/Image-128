=== How to Use This Guide

Code listings are in C64List form, as the BASIC source in the Image BBS 128 repository is (`im 128.bas`, `modules/*.lbl`).
Text in curly braces, such as `\{f6\}`, `\{white\}` or `\{pound\}`, stands for a key to type.
We deliberately chose a character not available on the Commodore keyboard; just type what the text in the curly braces represents: kbd:[f6] for `\{f6\}`, kbd:[Ctrl+2] for `\{white\}`, kbd:[£] for `\{pound\}`.
A control key that C64List has no name for is written as its character code, `{$xx}` in hex: `{$04}` is kbd:[Ctrl+D].
Inside quotes, control codes such as `\{f6\}` are shown in reverse field, as the 128 shows them in quote mode.

On the 128, a memory location in a listing is written as its name from `asm/equates.asm`, in C64List's `+{sym:name}+` form: `+poke {sym:modclmn},ll%+`, not `poke 6267,ll%`.
The build puts the number in.
The numbers, and the C64 locations they replace, are in <<pokes>>.
Image BBS 128's BASIC is BASIC 7.0: modules that use its keywords (`instr`, `do`/`loop`, `begin`/`bend`...) are built with C64List 4.06 and include `Basic70.bas`.
